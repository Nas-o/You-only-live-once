## 长期方向

- 本地数据加密与可选端到端同步（默认关闭，不以云为依赖）
- 报告模板与领域知识库（学习/健身/写作/编程）
- 「时间校准」助手：基于历史偏差给预计时间建议
- 离线成就分享卡片（不引入社交比较排行榜）
- 多语言（英文优先）

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 报告门禁被视为负担 | 明确文案、示例数据、10 分钟引导；真实提交后立刻进入计时 |
| 多任务并行导致质量下降 | 默认上限 3，统计展示并行占比与切换成本；不鼓励无限并行 |
| 长时间计时数据丢失 | 15s 心跳 + 收功结算 + 重启自动暂停 + 原子写入与备份 |
| JSON 数据膨胀 | 事件/会话裁剪（300 条事件、会话按需归档）；后续迁移 SQLite |
| 平台 UI 重复实现 | `packages/desktop-ui` 已抽出；Android 只做移动布局变体 |
| Windows 未实机验收 | 保留源码/打包链路，优先在 Windows CI 上跑 DPI、IME、安装包验收 |
